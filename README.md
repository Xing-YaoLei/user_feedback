# 设备测量数据合并工具

质检把多台设备导出的宽表 CSV 合并成一份测量明细。同一个样件在同一检测轮次里可能被
两台设备都报了长度，而且旧模板的 `L` 用毫米、新模板的 `L` 用英寸。工具按
**JSON 字段字典** 完成单位换算、读数剔除、多来源比对、派生项计算，并把冲突交给
质检复核；新增模板时维护人员只改字典，不改代码。

## 用法

```bash
# 批量处理一个目录下的全部 CSV
python3 convert.py --dict dictionary.json --csv-dir samples --out out

# 或指定若干文件（目录与文件名重复时只处理一次）
python3 convert.py --dict dictionary.json --out out a.csv b.csv
```

仅依赖 Python 3 标准库。CSV 每行需带样件号、检测轮次和模板版本三列（列名由字典声明）。

## 处理流程

1. **读取与换算**：按 `模板版本` 选字典里对应版本的列映射；原值先用 `Decimal`
   乘以 `factor` 换算到标准单位（英寸→毫米为 25.4，不换算为 1）。
2. **剔除无效读数**：换算后按标准单位的 `[min, max]` 闭区间判定。空值、非数字、
   超范围、字典声明但 CSV 中不存在的列，以及缺少样件号/轮次的整行，都记入
   `rejections.csv`，不影响同一样件其他测量项。
3. **多来源比对**：同一样件、轮次、测量项下，剩余读数的最大值与最小值之差
   **不超过**该测量项 `tolerances` 里配置的允许偏差时：
   - 采用优先级最高的来源；同优先级按文件名、行号取第一条；
   - 所有参与比对的读数都写入 `sources.csv`，并标出哪条被采用。
   差值超出允许偏差时，全部读数写入 `conflicts.csv`，该测量项不产生有效值，
   交质检复核。
4. **派生项**：字典可定义派生项，公式用 `{测量项}` 引用其他测量项，也可以引用
   其他派生项，例如 `{总长} - 2 * {端部余量}`、`{净长} - 2 * {框边厚}`。
   输入项缺测、全部被剔除或处于冲突时，派生项记入 `uncomputable.csv`，
   写明阻塞它的测量项和原因；沿依赖链会给出根因。
5. **字典校验**：处理任何数据之前先校验字典——重复键、未知字段、同一版本内的
   重复映射、未知引用、循环依赖、标准单位不一致、缺少允许偏差等，发现问题立即
   停止并返回退出码 2。派生公式只做数值运算、不做单位换算，因此引用的测量项必须
   与派生项同单位。

计算全部使用 `Decimal`（50 位精度上下文），不做二进制浮点运算，也不使用 `eval`。

## 测试

```bash
python3 -I tests.py     # 行为测试，全部通过时退出码为 0
```

## 输出文件

均以 UTF-8 带 BOM 写出，可直接用 Excel 打开，并按样件号、检测轮次、测量项排序
（样件号里的数字按自然顺序，`S2` 排在 `S10` 前）。

| 文件 | 内容 |
|---|---|
| `measurements.csv` | 有效明细：来源类型（设备读数/派生）、标准值、标准单位，以及采用读数的模板版本、原文件、行号、列名、原值、原单位、优先级、参与比对的读数个数；派生项附计算式和输入明细 |
| `sources.csv` | 参与比对的每一条读数：标准值、来源与可追溯信息、优先级、是否采用（是/否/冲突） |
| `conflicts.csv` | 超出允许偏差的整组读数，逐条列出，附允许偏差、最大差、读数个数 |
| `uncomputable.csv` | 无法计算的派生项：计算式、阻塞测量项、原因 |
| `rejections.csv` | 剔除清单：空值 / 非数字 / 超范围 / 换算失败 / 缺列 / 缺少样件号 / 缺少检测轮次 / 列数与表头不符 |
| `unknown_versions.csv` | 模板版本缺失或无法识别的整行 |

## 字段字典（dictionary.json）

```json
{
  "sample_id_column": "样件号",
  "round_column": "检测轮次",
  "version_column": "模板版本",
  "default_priority": 0,
  "sources": { "device_a.csv": 10, "device_b.csv": 20 },
  "tolerances": { "总长": "0.05", "宽度": "0.1", "端部余量": "0.05" },
  "versions": {
    "TPL-1.0": {
      "columns": [
        {
          "source_column": "L",
          "item": "总长",
          "source_unit": "mm",
          "standard_unit": "mm",
          "factor": "1",
          "min": "90",
          "max": "110"
        }
      ]
    },
    "TPL-2.0": {
      "columns": [
        {
          "source_column": "L",
          "item": "总长",
          "source_unit": "in",
          "standard_unit": "mm",
          "factor": "25.4",
          "min": "90",
          "max": "110"
        }
      ]
    }
  },
  "derived": [
    { "item": "净长", "standard_unit": "mm", "formula": "{总长} - 2 * {端部余量}" }
  ]
}
```

| 键 | 说明 |
|---|---|
| `sample_id_column` / `round_column` / `version_column` | 三列元数据列名，不能重复 |
| `sources` | 文件名（不含路径）→ 优先级整数，数字越大越优先；未列出的文件用 `default_priority`（默认 0） |
| `tolerances` | 每个标准测量项的允许读数偏差（标准单位）；**必须覆盖全部标准测量项**，不能给派生项配置 |
| `versions.<版本>.columns` | 该版本的原列 → 标准测量项映射；同一版本内原列和测量项都不能重复，跨版本的标准单位必须一致 |
| `columns[].factor` | 标准值 = 原值 × factor，写成字符串保证十进制精确 |
| `columns[].min` / `max` | 标准单位的闭区间，可省略或为 `null` |
| `derived[]` | 派生项：`item`、`standard_unit`、`formula`；公式只允许数字、`{测量项}`、`+ - * /`、括号和一元正负号 |

### 新增模板版本

1. 在 `versions` 下以设备导出的版本字符串为键新增一节；
2. 为每个需要转换的列添加一条映射，填好 `factor`、`min`、`max`；
3. 数值一律写成字符串，保证十进制精确换算；
4. 若引入了新的标准测量项，记得在 `tolerances` 里补上允许偏差；
5. 保存后直接跑工具：任何字典问题都会在**处理数据之前**报出并以退出码 2 停止。

## 示例

`samples/` 下有三份示例导出：

- `device_a.csv`（`TPL-1.0`，毫米）
- `device_b.csv`（`TPL-2.0`，英寸）
- `device_c.csv`（`TPL-1.0`，毫米，优先级与 `device_a` 相同）

覆盖了跨模板比对、同优先级按文件名取第一条、超偏差冲突、空值、非数字、超范围、
未知版本、缺样件号，以及派生项可计算 / 被缺测阻塞 / 被冲突阻塞等情形。运行：

```bash
python3 convert.py --dict dictionary.json --csv-dir samples --out out
```

例如 `S001`/`R1`：`device_b` 的 `L=3.945 in` 换算为 `100.203 mm`，与 `device_a` 的
`100.2 mm` 相差 `0.003`，未超过 `总长` 的允许偏差 `0.05`，因此采用优先级更高的
`device_b` 读数；`S002`/`R1` 的 `总长` 两台设备相差 `0.12`，超出允许偏差，整组进入
`conflicts.csv`，依赖它的 `净长` 随之记为无法计算。
